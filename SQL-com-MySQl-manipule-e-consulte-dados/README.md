# 📘 SQL com MySQL: manipule e consulte dados

Este repositório contém anotações, exemplos e exercícios práticos sobre **SQL com MySQL**, abordando desde conceitos básicos.
O objetivo é servir como guia de estudo e referência para quem deseja aprender a manipular e consultar dados em bancos de dados relacionais.
